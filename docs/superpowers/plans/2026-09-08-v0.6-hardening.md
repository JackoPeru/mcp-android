# MCP Android v0.6 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make MCP Android's existing updater, RPC transport and foreground service safer and more reliable for autonomous use.

**Architecture:** Preserve the existing Tailscale + bearer-token HTTP boundary and 47-tool MCP interface. Add small pure-Java policy helpers for signer validation, lock domains and VPN recovery, then wire those policies into the current Android services without broad refactors.

**Tech Stack:** Java 17 Android app (minSdk 30, targetSdk 35), Node.js 24 MCP bridge, Gradle/JUnit 4, GitHub Actions, PowerShell release tooling.

**Spec:** `docs/superpowers/specs/2026-09-08-v0.6-hardening-design.md`

## Global Constraints

- Standard features require no root and no ADB.
- Remote endpoint remains bound only to Tailscale IPv4 `100.64.0.0/10`.
- Bearer token stays out of URLs, logs and diagnostics.
- Existing MCP tool names and schemas remain compatible.
- UI/password redaction and SAF root boundaries must remain intact.
- Android update installation still requires user confirmation.
