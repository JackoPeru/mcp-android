# MCP Android v0.7 Agent Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an agent-native Android control loop that combines compact observation, state synchronization, action+observation, local bounded flows, richer gestures, capability routing and diagnostics while preserving the existing security model.

**Architecture:** Add focused runtime components beside the existing Accessibility/RPC services rather than expanding `RpcDispatcher` further. `ScreenSnapshotStore` owns sanitized semantic snapshots/diffs, `UiLoopEngine` orchestrates idle/change/scroll-to/act-and-observe, `FlowRuntime` executes a strict JSON DSL, and `CapabilityRouter` centralizes optional backend availability. The Node bridge adds typed schemas for the new additive tools while keeping all existing 47 tools compatible.

**Tech Stack:** Android Java 17, AccessibilityService, Android system APIs, SAF, NotificationListenerService, Shizuku 13.1.5, Termux RUN_COMMAND, Node.js 24, MCP TypeScript SDK, Zod, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-09-08-v0.7-agent-loop-design.md`

## Global Constraints

- Android 11+ / minSdk 30.
- Standard operation must not require root or ADB.
- Remote HTTP server binds only to numeric Tailscale IPv4 in `100.64.0.0/10`.
- Existing bearer-token, locked-screen, password-redaction, SAF-root and notification permission boundaries remain unchanged.
- Shizuku and Termux remain explicit opt-in backends; no silent privilege escalation.
- Existing 47 MCP tools remain backward compatible.
- Screenshots are opt-in for new composite tools.
- Snapshot cache is memory-only, maximum 8 snapshots.
- Flow DSL has no shell, SAF mutation, arbitrary JavaScript/reflection or unbounded loops.
- Flow maximum: 40 steps, 20-second total deadline, bounded per-step scrolling.
- Mutating actions are never blindly retried after outcome-unknown timeouts.
