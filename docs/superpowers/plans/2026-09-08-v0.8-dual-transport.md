# MCP Android v0.8 Dual LAN/Tailscale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure, low-power dual transport so MCP Android is reachable over local Wi-Fi LAN at home and Tailscale remotely, with automatic LAN-first selection in the PC bridge.

**Architecture:** Split the current single-address HTTP server into reusable per-endpoint listeners managed by a transport reconciler. Android exposes independent LAN and Tailscale listeners plus a bounded UDP LAN discovery responder; the Node bridge validates/configures both transports and selects LAN first without replaying outcome-unknown mutating RPCs.

**Tech Stack:** Android Java, java.net TCP/UDP sockets, Android ConnectivityManager/NetworkCallback, Node.js built-in fetch/dgram/net APIs, MCP TypeScript SDK, JUnit 4, Node test runner, Gradle.

**Spec:** `docs/superpowers/specs/2026-09-08-v0.8-dual-transport-design.md`

## Global Constraints

- RPC TCP port remains **8765**.
- LAN discovery UDP port is **8766**.
- LAN listener only binds explicit RFC1918 Wi-Fi IPv4 addresses.
- Tailscale listener only binds explicit IPv4 addresses in **100.64.0.0/10**.
- Never bind `0.0.0.0` or `::`.
- Bearer token remains 64 lowercase hex characters / 256 bits and is required on every RPC transport.
- LAN discovery never contains the bearer token or device-identifying/private content.
- LAN requests must come from the selected Wi-Fi subnet.
- No mDNS, multicast group, multicast lock, UPnP, NAT-PMP or public listener.
- Network changes are callback-driven; the safety watchdog remains **15 minutes** while START and zero while STOP.
- Existing v0.7.2 STOP low-power behavior must remain intact.
- Mutating RPCs must never be replayed automatically after an outcome-unknown transport failure.
- Existing Tailscale-only configuration remains supported.
- Target release: **v0.8.0**, versionCode **11**, package `com.example.androidmcp`, same signer as v0.7.2.

```java
public final class NetworkAddressPolicy {
    private static long ipv4(String ip) {
        if (ip == null) throw new IllegalArgumentException("IPv4 required");
        String[] parts = ip.split("\\.", -1);
        if (parts.length != 4) throw new IllegalArgumentException("Invalid IPv4");
        long value = 0;
        for (String part : parts) {
            if (part.isEmpty() || part.length() > 3) throw new IllegalArgumentException("Invalid IPv4");
            int octet = Integer.parseInt(part);
            if (octet < 0 || octet > 255) throw new IllegalArgumentException("Invalid IPv4");
            value = (value << 8) | octet;
        }
        return value;
    }
    public static boolean isRfc1918(String ip) {
        long v = ipv4(ip);
        return (v & 0xff000000L) == 0x0a000000L
                || (v & 0xfff00000L) == 0xac100000L
                || (v & 0xffff0000L) == 0xc0a80000L;
    }
    public static boolean isTailscale(String ip) {
        return (ipv4(ip) & 0xffc00000L) == 0x64400000L;
    }
    public static boolean subnetContains(String ip, int prefix, String candidate) {
        if (prefix < 0 || prefix > 32) throw new IllegalArgumentException("Invalid prefix");
        long mask = prefix == 0 ? 0 : (0xffffffffL << (32 - prefix)) & 0xffffffffL;
        return (ipv4(ip) & mask) == (ipv4(candidate) & mask);
    }
    public static String broadcastAddress(String ip, int prefix) {
        if (prefix < 1 || prefix > 30) throw new IllegalArgumentException("Invalid LAN prefix");
        long mask = (0xffffffffL << (32 - prefix)) & 0xffffffffL;
        long value = (ipv4(ip) & mask) | (~mask & 0xffffffffL);
        return ((value >>> 24) & 255) + "." + ((value >>> 16) & 255) + "."
                + ((value >>> 8) & 255) + "." + (value & 255);
    }
}

public final class TransportEndpoint {
    public final String transport;
    public final String address;
    public final int port;
    public final int prefixLength;
}
```

Validation rules:
- reject malformed IPv4;
- prefix must be 0..32 internally, but LAN call sites must require 1..30 for broadcast discovery;
- endpoint transport must be exactly `lan` or `tailscale`;
- port must be 1..65535.
